Coordenadas cilíndricas

Localize um ponto no espaço

A distância r é medida até o eixo z, φ indica a direção no plano xy e z determina a altura do ponto.

Escolha Variar φ, Variar z ou Variar r para arrastar o ponto mantendo as outras duas coordenadas fixas. A linha dourada mostra o caminho permitido.

\(x=r\cos\phi\), \(y=r\sin\phi\), \(z=z\).
\(r\geq0,\;0\leq\phi<2\pi,\;z\in\mathbb R\).

Arraste a bolinha roxa para variar as coordenadas. Use Girar vista para mudar o ponto de observação e a roda do mouse para dar zoom.
