Gráfico de curvas planas em coordenadas polares
Neste projeto apresentamos como se constrói o gráfico de curvas planas em coordenadas polares, sempre respeitando a condição r = √(x² + y²) maior ou igual a zero.
O que implica que as rosáceas sejam r = a cos(nθ) ou r = a sin(nθ) sempre terão n pétalas. Aqui, a é um número real constante e n é um número inteiro, diferente de zero.
Use theta como variável. Funções: sin, cos, tan, abs, sqrt, exp, pow, + - * /
Ex: 0 , 2*pi , 0.02 (o passo é ajustado automaticamente conforme o tamanho do gráfico)
Curva 2 tem janela própria. Marque apenas a curva 1, apenas a 2, ou as duas.
📌 intervalos rápidos:
0 → 2π 0 → π 0 → 4π (2 voltas) -π → π
⚡ r ≥ 0 sempre tratado como positivo | se r<0 -> |r| é traçado (módulo).
